# LPIC-2 Exam 202: Linux Network and System Security

## Overview

Exam 202 focuses on network services configuration, security implementation, and infrastructure services that enable Linux systems to function effectively in enterprise environments. This exam validates advanced skills in network administration, security, and service management.

## Exam Details

- **Exam Code**: 202-450
- **Duration**: 90 minutes
- **Questions**: Approximately 60 questions
- **Passing Score**: 500 out of 800 points
- **Prerequisites**: Valid LPIC-1 certification and Exam 201
- **Validity**: 5 years

## Topics and Weightings

**Subtopics:**
- 207.1 Basic DNS Server Configuration (Weight: 3)
- 207.2 Create and Maintain DNS Zones (Weight: 3)
- 207.3 Securing a DNS Server (Weight: 2)

Web server implementation, SSL/TLS configuration, and proxy services.

**Subtopics:**
- 208.1 Implementing a Web Server (Weight: 4)
- 208.2 Apache Configuration for HTTPS (Weight: 3)
- 208.3 Implementing a Proxy Server (Weight: 2)

### Topic 209: File Sharing (Weight: 5)
Network file sharing protocols and server configuration.

**Subtopics:**

## Study Approach

1. **Foundation**: Ensure solid understanding of networking fundamentals
2. **Service Configuration**: Practice configuring each network service
3. **Security Focus**: Emphasize security best practices and implementations
4. **Integration**: Understand how services work together in enterprise environments
5. **Troubleshooting**: Develop skills in diagnosing and resolving service issues

## Key Skills Validated

- DNS server administration and security
- Web server configuration and SSL/TLS implementation
- File sharing services (Samba, NFS)
- Network client management (DHCP, LDAP, PAM)
- Email services configuration and management
- Network security and VPN implementation
- System hardening and access control

## Enterprise Focus

This exam emphasizes real-world enterprise scenarios including:
- Multi-service integration
- Security best practices
- Performance optimization
- High availability considerations
- Monitoring and maintenance
